═══════════════════════════════════════════════════════════════════════════════
                    HƯỚNG DẪN OBFUSCATION CODE VỚI PROGUARD
                    Cho Maven Projects (Bukkit/Spigot Plugins)
═══════════════════════════════════════════════════════════════════════════════

📋 MỤC LỤC:
1. Cài đặt ProGuard Maven Plugin
2. Tạo file proguard.conf
3. Tạo file obfuscation-dictionary.txt
4. Cấu hình pom.xml
5. Build và sử dụng

═══════════════════════════════════════════════════════════════════════════════

1. CÀI ĐẶT PROGUARD MAVEN PLUGIN
═══════════════════════════════════════════════════════════════════════════════

Thêm vào file pom.xml trong thẻ <build><plugins>:

<!-- ProGuard Maven Plugin - Obfuscate code -->
<plugin>
    <groupId>com.github.wvengen</groupId>
    <artifactId>proguard-maven-plugin</artifactId>
    <version>2.6.0</version>
    <dependencies>
        <dependency>
            <groupId>com.guardsquare</groupId>
            <artifactId>proguard-base</artifactId>
            <version>7.2.2</version>
        </dependency>
    </dependencies>
    <executions>
        <execution>
            <phase>package</phase>
            <goals>
                <goal>proguard</goal>
            </goals>
        </execution>
    </executions>
    <configuration>
        <proguardVersion>7.2.2</proguardVersion>
        <obfuscate>true</obfuscate>
        <injar>${project.build.finalName}.jar</injar>
        <outjar>${project.build.finalName}-obfuscated.jar</outjar>
        <outputDirectory>${project.build.directory}</outputDirectory>
        <attach>true</attach>
        <attachArtifactClassifier>obfuscated</attachArtifactClassifier>
        <libs>
            <!-- Java 9+ không còn rt.jar, ProGuard sẽ tự động tìm Java runtime -->
        </libs>
        <proguardInclude>proguard.conf</proguardInclude>
    </configuration>
</plugin>

═══════════════════════════════════════════════════════════════════════════════

2. TẠO FILE proguard.conf
═══════════════════════════════════════════════════════════════════════════════

Tạo file proguard.conf ở thư mục gốc của project với nội dung:

# ProGuard Configuration File
# Bỏ qua warning về Java standard library (sẽ có sẵn khi chạy trên server)
-dontwarn java.**
-dontwarn javax.**

# Giữ lại toàn bộ enum classes (bao gồm inner enums) - KHÔNG obfuscate
-keep enum * {
    *;
}

# Giữ lại tên enum classes (không đổi tên)
-keepnames enum * {
    *;
}

# Giữ lại enum methods cho tất cả enum (kể cả inner enums)
-keepclassmembers enum * {
    public static **[] values();
    public static ** valueOf(java.lang.String);
    public int ordinal();
    public java.lang.String name();
}

# Keep cụ thể các enum classes nếu cần (thay đổi package name cho phù hợp)
# -keep class com.example.yourpackage.manager.RewardManager$Reward$Rarity {
#     *;
# }

# Giữ lại các class cần thiết cho Bukkit
-keep public class com.example.yourpackage.YourMainClass { *; }
-keep class com.example.yourpackage.YourMainClass$* { *; }
-keep public class com.example.yourpackage.command.** { *; }
-keep public class com.example.yourpackage.listener.** { *; }

# Obfuscate các manager, model, util, license (internal classes)
-keep class com.example.yourpackage.manager.** {
    public <init>(...);
    public *;
}

# Giữ lại toàn bộ inner enum classes trong manager
-keep class com.example.yourpackage.manager.**$*$* {
    *;
}

-keep class com.example.yourpackage.model.** {
    public <init>(...);
    public *;
}

-keep class com.example.yourpackage.util.** {
    public *;
}

# Keep toàn bộ LicenseClient (bao gồm private fields) để tránh duplicate field names
# QUAN TRỌNG: Nếu có class nào bị lỗi "Duplicate key" khi chạy trên server,
# cần keep toàn bộ class đó (không chỉ public methods)
-keep class com.example.yourpackage.license.LicenseClient {
    *;
}

-keep class com.example.yourpackage.license.** {
    public *;
}

-keep class com.example.yourpackage.security.** {
    public *;
}

# Giữ lại các annotation và metadata cần thiết
-keepattributes *Annotation*
-keepattributes Signature
-keepattributes Exceptions
-keepattributes SourceFile,LineNumberTable
-keepattributes EnclosingMethod

# Obfuscate tên class và method với dictionary
-obfuscationdictionary obfuscation-dictionary.txt
-classobfuscationdictionary obfuscation-dictionary.txt
-packageobfuscationdictionary obfuscation-dictionary.txt

# Tắt optimization để tránh lỗi incomplete class hierarchy với Bukkit API
-dontoptimize
-dontpreverify

# Obfuscate mạnh (không optimize)
-allowaccessmodification
-repackageclasses ''
-overloadaggressively
-useuniqueclassmembernames
-dontskipnonpubliclibraryclasses
-dontskipnonpubliclibraryclassmembers

# Bỏ qua warnings (sẽ có sẵn khi chạy trên server)
-ignorewarnings

# Bỏ qua incomplete class hierarchy (Bukkit API có thể không đầy đủ trong library jars)
-dontwarn org.bukkit.entity.Entity
-dontwarn org.bukkit.projectiles.ProjectileSource
-dontwarn org.bukkit.**

# Bỏ qua warning về unresolved references (sẽ có sẵn khi chạy)
-dontwarn org.bukkit.Material

# Giữ lại các method cần thiết cho Bukkit
-keepclassmembers class * {
    @org.bukkit.event.EventHandler *;
}

-keepclassmembers class * implements org.bukkit.command.CommandExecutor {
    *;
}

-keepclassmembers class * implements org.bukkit.command.TabCompleter {
    *;
}

-keepclassmembers class * implements org.bukkit.event.Listener {
    *;
}

# Giữ lại các method public và constructor
-keepclassmembers class * {
    public <init>(...);
    public <methods>;
}

4. CẤU HÌNH pom.xml
═══════════════════════════════════════════════════════════════════════════════

QUAN TRỌNG: Đảm bảo maven-shade-plugin được cấu hình ĐÚNG:

<plugin>
    <groupId>org.apache.maven.plugins</groupId>
    <artifactId>maven-shade-plugin</artifactId>
    <version>3.2.4</version>
    <executions>
        <execution>
            <phase>package</phase>
            <goals>
                <goal>shade</goal>
            </goals>
            <configuration>
                <createDependencyReducedPom>false</createDependencyReducedPom>
                <!-- Quan trọng: Attach shaded artifact với classifier -->
                <shadedArtifactAttached>true</shadedArtifactAttached>
                <shadedClassifierName>shaded</shadedClassifierName>
            </configuration>
        </execution>
    </executions>
</plugin>

LƯU Ý: ProGuard sẽ sử dụng file JAR chính (đã được shade) làm input.

═══════════════════════════════════════════════════════════════════════════════

5. BUILD VÀ SỬ DỤNG
═══════════════════════════════════════════════════════════════════════════════

Bước 1: Build project
    mvn clean package

Bước 2: Kiểm tra file đã tạo
    - File gốc: target/YourProject-1.0-SNAPSHOT.jar
    - File shaded: target/YourProject-1.0-SNAPSHOT-shaded.jar
    - File obfuscated: target/YourProject-1.0-SNAPSHOT-obfuscated.jar ⭐

Bước 3: Sử dụng file obfuscated
    - Copy file -obfuscated.jar vào thư mục plugins của server
    - File này đã được obfuscate và sẵn sàng sử dụng

═══════════════════════════════════════════════════════════════════════════════

⚠️ LƯU Ý QUAN TRỌNG:
═══════════════════════════════════════════════════════════════════════════════

1. THAY ĐỔI PACKAGE NAME:
   - Thay "com.example.yourpackage" bằng package name thực tế của bạn
   - Thay "YourMainClass" bằng tên main class của bạn

2. GIỮ LẠI CÁC CLASS QUAN TRỌNG:
   - Main plugin class (phải giữ nguyên)
   - Command classes (phải giữ nguyên)
   - Listener classes (phải giữ nguyên)
   - Enum classes (phải giữ nguyên)

3. OBFUSCATE CÁC CLASS INTERNAL:
   - Manager classes (có thể obfuscate)
   - Model classes (có thể obfuscate)
   - Util classes (có thể obfuscate)
   - License classes (có thể obfuscate)
   - Security classes (có thể obfuscate)

4. NẾU GẶP LỖI:
   - Lỗi "incomplete class hierarchy": Đã được xử lý bằng -dontoptimize
   - Lỗi "can't find referenced method": Thêm -dontwarn cho class đó
   - Lỗi "can't find referenced class": Thêm -dontwarn cho package đó
   - Lỗi "Duplicate key" khi chạy trên server: Keep toàn bộ class đó:
     -keep class com.example.yourpackage.YourClass {
         *;
     }

5. TESTING:
   - Luôn test file obfuscated trên server test trước
   - Đảm bảo tất cả chức năng hoạt động bình thường
   - Kiểm tra logs để đảm bảo không có lỗi

📝 VÍ DỤ CẤU HÌNH CHO DỰ ÁN KHÁC:
═══════════════════════════════════════════════════════════════════════════════

Nếu package của bạn là: com.myserver.myplugin

Thì trong proguard.conf, thay đổi:
-keep public class com.example.yourpackage.YourMainClass { *; }
Thành:
-keep public class com.myserver.myplugin.MyPlugin { *; }

Và tương tự cho các package khác:
-keep public class com.myserver.myplugin.command.** { *; }
-keep public class com.myserver.myplugin.listener.** { *; }
-keep class com.myserver.myplugin.manager.** { ... }

🎯 KẾT QUẢ:
═══════════════════════════════════════════════════════════════════════════════

Sau khi build thành công, bạn sẽ có:
- File obfuscated với tên class/method đã bị thay đổi thành tên ngắn gọn
- Code khó reverse-engineer hơn
- File size có thể nhỏ hơn một chút do optimization
